# 영어 학원 모의고사 분석 에이전트 — 설계

작성일 2026-11-08 · 제출 마감 2026-11-11 23:59 · 평가용 데이터는 120명, 개발용 샘플은 10명(동일 형식 가정)

## 1. 목적과 이유
가천대 부트캠프 최종 평가. "영어 학원 원장님"이 문제지 PDF·OMR 엑셀·정답 PDF를 올리면 자동 채점하고,
엑셀로 결과를 내려받고, 채점 결과에 대해 챗봇으로 질문(통계, 학생 점수, 유사 문제 생성)하는 웹 서비스.
배점: 웹/배포 10 · 자동채점 10 · 엑셀 10 · 채팅 10 · **채팅 세부 60(질문 6개 × 10점, 부분점수 없음, 20초 초과 시 오답)**.
→ 점수의 60%가 챗봇 6문항의 정확성과 속도에 달려 있다. 설계의 최우선 기준은 **정확성 > 20초 이내 응답 > 나머지**.

## 2. 목표 / 비목표 / 안티골
- 목표: 요구사항 1~5 전부 충족, 다른 선생님이 URL로 접속해 바로 사용, 마감 이후에도 서비스 유지.
- 비목표: 로그인, DB, 대화 내역 영구 저장(요구사항에서 불필요하다고 명시), 다중 시험 비교.
- 안티골: 정답/배점을 코드나 별도 파일에 하드코딩(명시적 금지), 평균·점수를 LLM이 암산해서 틀리는 것,
  내부 도구 구성 노출(인젝션 평가 항목), 20초 초과.

## 3. 결정과 이유 (README의 "기술 선택 이유"에 그대로 옮긴다)
| 결정 | 선택 | 이유 |
|---|---|---|
| 언어 | Python | pandas·PDF·엑셀·OpenAI SDK가 모두 1급 지원. |
| 웹 | Streamlit (멀티페이지) | 사이드바 업로더·채팅 입력·다운로드 버튼이 기본 제공. README 예시 URL도 streamlit.app. 직접 프론트를 만들 이유가 없음. |
| 배포 | Streamlit Community Cloud | GitHub 연결만으로 무료 배포, API 키는 Secrets로 관리(저장소 비노출). 단점: 장시간 미접속 시 슬립 → 제출 전 접속해 깨워 두고 README에 명시. |
| 랭체인 | **쓰지 않음** | 이 서비스의 LLM 사용은 "분류 1회 + 문장 생성 1회"뿐이라 체인/추상화가 필요 없음. OpenAI SDK 직접 호출이 더 짧고, 추가 의존성은 배포 실패·지연·디버깅 난이도만 키움. 대화 기억도 메시지 리스트 하나로 충분. |
| 랭그래프 | **쓰지 않음** | 흐름이 `분류 → 도구 실행 → 답변` 직선 하나. 상태 그래프·루프·분기 병렬이 없어 그래프로 표현할 이득이 없고, 노드 수만큼 LLM 호출이 늘면 20초 제한에 불리. |
| "에이전트" 구현 | 직접 구현한 라우터 + 도구 | 도구는 5개 내외의 고정 함수. 모델이 자유롭게 계획하는 에이전트 루프는 느리고 비결정적이라 오히려 감점 위험. |
| 질문 분류 | **OpenAI Decisions API(`/v1/decisions`) → 실패 시 function calling으로 자동 대체** | 선택지 분류에 특화된 빠른 엔드포인트라 20초 예산에 유리. 단 공개 베타이고 공식 문서를 확인하지 못했으므로 단독 의존하지 않음(타임아웃/에러/낮은 확신도면 function calling). |
| 숫자 계산 | pandas (코드) | 평균·중앙값·표준편차·점수는 LLM이 계산하면 틀릴 수 있음. LLM은 결과를 문장으로만 옮긴다. |
| 정답 추출 | 업로드한 정답 PDF를 파싱 | 요구사항(2)에서 코드/별도 파일 하드코딩 금지. |

## 4. 구조
```
app.py              # 페이지 1: 랜딩 (소개 + 2페이지로 가는 버튼)
pages/analysis.py   # 페이지 2: 사이드바(업로드 3종, 분석 시작, 엑셀 추출) + 채팅
core/answer_key.py  # 정답 PDF → {문항: (정답, 배점)}
core/problems.py    # 문제지 PDF → {문항: 본문 텍스트}
core/grading.py     # OMR 엑셀 + 정답 → 학생별 점수/문항별 정오 (pandas)
core/export.py      # 결과 → 엑셀 bytes
core/chat.py        # 분류(Decisions→fallback) → 도구 실행 → 답변 생성
tests/              # 파서/채점 smoke test (샘플 데이터 기준)
README.md           # 학번·이름·배포 URL·기술 선택 이유
```
세션 상태(`st.session_state`)에 채점 결과와 대화 메시지를 보관. DB 없음.

## 5. 동작 상세
**채점**: 분석 시작 → 정답 PDF 파싱, OMR 엑셀 로드, 문항별 정오 판정, 점수 = 맞힌 문항 배점 합(합계 100점).
빈칸/잘못된 값은 오답. 채점 완료 시에만 엑셀 추출 버튼과 채팅 입력 활성화.

**정답 PDF 파싱(확인됨)**: 3열 표에 `문항 정답 배점`이 이어 붙은 형태(원문자 ①~⑤). 좌표 기반 또는 토큰 정규식으로
45문항 전부 추출하고, **문항 수 45, 배점 합 100을 assert**해서 틀리면 사용자에게 오류 표시.

**문제지 PDF 파싱(확인됨, 위험 요소)**: 2단 편집이라 단순 추출 시 두 단이 섞임. 페이지를 좌/우 절반으로 잘라
각각 추출한 뒤 문항 번호로 분할. 1~17번은 듣기 문항이라 **지문 스크립트가 PDF에 없음**
→ 이 문항이 최다 오답이면 "선택지·발문 기반의 같은 유형 문제"로 생성(스크립트도 함께 생성). 추출이 지저분한 문항은 LLM이 보정하도록 프롬프트.

**엑셀**: 시트 `전체 학생 성적 개요`(평균, 중앙값, 표준편차, 가장 많이 틀린 문항 3개와 오답 수),
시트 `전체 학생 결과`(학생 × 점수·문항별 O/X, 제 판단으로 추가), 그리고 요구사항 그림처럼
`N번 학생 점수 및 각 문제별 정답 여부` 시트를 학생 수만큼 생성.

**학생 지칭 규칙(제 판단)**: 샘플 학생명은 `900학생`~`909학생`인데 질문 예시는 "87번 학생"이라 모호함.
순서: ① 학생명 숫자가 일치하면 그 학생 ② 아니면 데이터 순서의 N번째 학생. 답변에 어느 학생인지(`N번째, 학생명`) 같이 표기.
둘 다 없으면 "해당 학생을 찾을 수 없다"고 답.

**채팅 흐름**
1. 입력 → 의도 분류. 라벨: `summary_stats`(평균/중앙값/표준편차), `lowest_student`, `student_score`, `hardest_questions`,
   `generate_similar_problem`, `out_of_scope`(데이터에 없는 정보), `meta_or_injection`(도구·시스템 정보 요구, 지시 무시 요구), `chitchat`.
2. 분류는 Decisions API 먼저(짧은 타임아웃 ≈3~4초). 에러·타임아웃·확신도 낮음 → function calling 대체.
3. 라벨에 해당하는 함수 실행(순수 pandas, 필요 시 학생 번호를 정규식으로 추출).
4. 결과 + 대화 이력을 LLM에 1회 전달해 한국어로 답변. LLM 호출이 제한 시간(≈12초)을 넘기면 도구 결과로 만든 고정 문장으로 대체.
5. `out_of_scope`는 "데이터에 없다"고 답하고, `meta_or_injection`은 내부 구성은 밝히지 않고 지원 기능만 안내. `chitchat`은 인사와 기능 소개.

**유사 문제 생성**: 가장 많이 틀린 문항(동률이면 배점 높은 순, 그다음 번호 순)의 본문을 근거로 같은 유형의 새 문제 1개
(지문·발문·선택지 5개·정답·짧은 해설).

## 6. 제약
- OpenAI API 키는 Streamlit Secrets와 로컬 `.env`로만 관리, 저장소 커밋 금지(`.gitignore`).
- 모델명은 설정 상수 한 곳에서 관리. 기본값은 빌드 중 사용자의 키로 지연 시간을 재 보고 확정.
- 20초 예산: 분류 ≤4초 + 답변 ≤12초 + 여유. 유사 문제 생성이 가장 느릴 것이므로 별도 측정.

## 7. 검증 (smoke test)
- 정답 파서: 45문항, 배점 합 100, 샘플 문항 일부(1번 ③ 2점, 30번 ⑤ 3점) 확인.
- 채점: 샘플 10명 점수를 손계산 1~2명과 대조.
- 챗봇: 평가 6문항 + "안녕하세요. 어떤 기능이 지원되나요?"를 각각 실행해 정답성과 20초 이내 여부 기록, 후속 질문(앞 대화 기억) 1건 확인.
- 엑셀: 시트 구성과 통계 값을 pandas 값과 대조.
